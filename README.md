## Windows 11 预览
1. 解压 ZIP，进入 `V15_2_Dreamlike_Violet_Resume` 文件夹。
2. 在文件夹地址栏输入 `powershell`，回车。
3. 执行 `py -m http.server 5173`（若无 py，改为 `python -m http.server 5173`）。
4. 在浏览器打开 `http://localhost:5173/#connect`。
